# Vamsi's Learning Blog

A personal blog application built with Node.js, Express and EJS.

## Tech Stack

- Node.js
- Express.js
- EJS
- JavaScript
- HTML
- CSS

## Features

- Server-side rendered pages using EJS
- Express routing
- Static asset handling
- Contact page
- Custom 404 page

## Running Locally

```bash
git clone https://github.com/vamsi8979/vamsi-8979.git
cd vamsi-8979
npm install
node app.js
